# study_python

Python 基础学习脚本，包含与 C/C++ 的语法对照。源码注释以 Python 3.10 为学习环境。

## 内容导航

- [easy_python.py](./easy_python.py)：语法、变量与语言对照笔记
- [numer_type.py](./numer_type.py)：数值类型练习
- [python_operator.py](./python_operator.py)：运算符
- [type_change.py](./type_change.py)：类型转换
- [circular_function.py](./circular_function.py)：循环练习
- [math_function.py](./math_function.py)：数学函数
- [random_num.py](./random_num.py)：随机数
- [hello.py](./hello.py)：入门脚本

## 运行

在仓库根目录选择单个脚本执行，例如：

```bash
python easy_python.py
```

部分脚本有交互输入或帮助页面，请在终端运行并根据提示操作。
